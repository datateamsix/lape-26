# LAPE-26 Word Explorer

A standalone browser prototype for entering words, names, and short phrases.

## Run

Open `index.html` directly, or serve the repository:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/apps/word-explorer/
```

Tone.js is currently loaded from a pinned CDN URL, so audio playback requires an internet connection.
