# Scripts

- `validate_mapping.py` verifies A-Z completeness, uniqueness, contiguous pitch-pool use, and frequency precision. It also writes a SHA-256 file.
- `evaluate_mapping.py` produces a small deterministic JSON report for supplied words or phrases.
- `check_cross_runtime.ts` confirms Python and TypeScript parity on shared golden vectors.

- `check_word_explorer_mapping.py` confirms the standalone app embeds the exact canonical mapping.
