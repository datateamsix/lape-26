# Changelog

All notable changes are documented here.

## [0.1.0-experimental] — 2026-07-29

### Added

- Initial LAPE-26 English experimental mapping
- Canonical JSON mapping and schema
- TypeScript and Python reference encoders
- Shared golden vectors
- Browser Word Explorer with melody and chord playback
- Phase 0 governance, specifications, data rules, and CI

### Research status

This release establishes a prototype and evaluation foundation. It does not freeze a permanent alphabet or claim scientifically proven word-to-pitch relationships.
