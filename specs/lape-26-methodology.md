# LAPE-26 Methodology v0.1

## Purpose

LAPE-26 is a creative research framework for rendering written language as deterministic musical events and studying the resulting structures.

## Physics layer

For MIDI note number `m`, frequency is:

```text
f(m) = 440 × 2^((m - 69) / 12)
```

This defines exact pitch frequencies in 12-tone equal temperament.

## Assignment layer

The assignment of letters to pitches is not dictated by physics. It is a versioned creative and empirical hypothesis that may be compared with alternatives.

## Current constraints

- 26 English letters
- 26 unique MIDI notes
- Pitch pool 48–73 inclusive
- A4 reference frequency of 440 Hz
- One letter maps to exactly one pitch
- One pitch is used by exactly one letter

## Research objective

A strong mapping should balance:

- Musical listenability
- Distinctive word identities
- Comfortable register use
- General-English behavior
- Name and lyric behavior
- Melody and chord behavior
- Reproducibility
- Interpretability

No single metric is treated as objective musical truth.
