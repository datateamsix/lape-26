# Listening Study Protocol — Pilot Draft

## Goal

Compare fixed candidate mappings without allowing instrument, tempo, loudness, or interface cues to dominate listener preference.

## Minimum controls

- Blind mapping labels
- Randomized presentation order
- Same input text
- Same instrument
- Same tempo and duration
- Loudness normalization
- No analysis shown before rating
- Anonymous session identifier

## Initial questions

1. Which version is more musical?
2. Which gives the word a more distinctive identity?
3. Which feels more fitting for the word?
4. Which would you prefer to hear repeatedly?
5. How tiring is each version?

## Privacy

Collect only information required for the study. Public exports must be anonymous and documented. A production human-subject study may require institutional or independent ethics review depending on context and intended publication.
