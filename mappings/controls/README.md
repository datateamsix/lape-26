# Control Mappings

Controls are required to determine whether a complex candidate outperforms simpler alternatives.

Planned controls:

- `sequential-chromatic`: A=C3 through Z=C#5
- `frequency-ranked`: common letters nearest the register center
- `circle-of-fifths`: alphabetical order advances by pitch-class fifths
- `random-seed-NNN`: reproducible uniform permutations

Phase 0 includes specifications and a placeholder directory. Phase 2 will add canonical generated files and comparative reports.
